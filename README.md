This is my project and it is an funny internet meme shop where you can pretend to buy various funny items, 1. selet the item you want 2. press add to cart 3. scroll down and select quantity 4. hit buy.
You dont actually get the items but the program calculates how much the selected items cost and then you get an message saying how much money you spent.
All of the items have unique descriptions so you know what you are(not)buying.
this project is inspired by the GeeksForGeeks grocery store website. NO AI WAS USED IN THIS PROJECT.
